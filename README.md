# ECHO Engine

**A Friday Night Funkin' engine focused on improvements, bug fixes, and new features.**

**Play online:** https://10574084-cmd.github.io/Echo-Engine-1.1.0

## About

ECHO Engine is an independent Friday Night Funkin' engine project focused on fixing existing issues, improving the gameplay experience, and introducing features that go beyond the original game.

The project is currently in beta. Development is ongoing, and some features may be incomplete, unstable, or not working as intended.

The goal is straightforward: build a better engine, fix the annoying shit that gets in the way, and keep improving it over time.

## Features and Goals

- **Bug fixes:** Identify and resolve issues affecting gameplay and functionality.
- **Mod support:** Improve compatibility with custom content.
- **Mod Select:** Develop a more convenient way to import and manage mods.
- **Web compatibility:** Make the engine playable through a web browser.
- **Future improvements:** Introduce additional features and quality-of-life changes as development progresses.

Features listed here may still be under development and are not guaranteed to be fully functional.

## Mod Support

Mod support is currently a work in progress.

Although the project includes work toward importing and managing mods, some mods may fail to load or function correctly. Compatibility depends on the mod's structure, assets, scripts, and the engine's current capabilities.

The priority is to make mod importing more reliable, improve loading behavior, and address the issues preventing mods from working properly.

For now, expect bugs. This is beta software, not a finished product.

## Development Status

ECHO Engine is actively being developed. Its current limitations include:

- Incomplete or unstable features.
- Mod-loading and compatibility issues.
- Potential gameplay bugs.
- Features that may change during development.

Updates may introduce new problems while resolving existing ones. Testing and bug reports are important for identifying these issues and improving the engine.

## Bug Reports

If you encounter a bug, please provide as much information as possible:

1. Describe what you were doing when the problem occurred.
2. Explain what you expected to happen.
3. Describe what actually happened.
4. Include reproduction steps when possible.

Clear reports make debugging easier and help avoid wasting time guessing what the hell went wrong.
